# Fréquence

Blind test multijoueur pour iPhone, inspiré des jeux de chronologie musicale.

- Un iPhone diffuse les extraits, les autres répondent depuis leur téléphone (code à 4 lettres ou QR code).
- Modes : **Blind test + bonus année** et **Chronologie** (placer le morceau dans sa frise).
- Extraits de 30 s fournis par Deezer (Apple Music en secours), sans compte.
- **Mode solo** et **16 mélodies intégrées** pour jouer sans internet.

Tout le jeu tient dans `index.html`. Ouvre-le dans Safari depuis l'adresse GitHub Pages, puis Partager → « Sur l'écran d'accueil ».
